# クラス図の差分同期：実装計画と進捗

[シーケンス図の計画](sequence-sync-plan.md)と同じ進め方を、別拡張 `ClassImportProbe` で繰り返す。共有部品を切り出さずに写したのは、クラス図で得た知見を独立に積み上げるため。

## 完成条件

表示中のクラス図で「PlantUMLを反映」を押し、ファイルを選ぶと、対応付け・照合・反映・読戻しまで完了する。PlantUMLを意味上の正本とし、共通部分のモデルID・図形ID・表示設定を保持する。図形の座標は新しい要素にだけ与え、既存要素は動かさない。図に載っていないモデルは変更しない。

対象はクラス（キーワード・ステレオタイプ）、属性、操作、列挙リテラル、参照関連（汎化・実現・依存・集約・合成・関連）、所有先（package・図上の親ノード）。識別子コメントをPlantUMLに追加しない。プロジェクトを自動保存しない。反映は一つのトランザクションに収め、失敗時は取消と復元の読戻しを行う。

## 前提

- クラス図は `EditorType == "ERDiagram"`（一部 `"TreeDiagram"`）で型付きアクセサがない。`IDiagram.Nodes / Connectors` とモデル側のメタクラス・フィールドで意味を取る。読取り経路は PlantUmlTool の出力処理と同じ規則を写した。
- 実機プロファイルのクラス図メタモデル（属性・操作・関連のフィールド名）は未記録。対応表は推測から始め、「クラス図調査」の実測で埋める。実測値はローカル知識へ保存し、この文書には書かない。
- Editor JSON では属性・操作がノードの `Compartments[].Items[].ModelId` として載る（公式サンプルの観測）。実機の形は「クラス図調査」の退避で確認する。
- ImportUnitFromJson・関連の順序番号・Undo/Redo・エディタ再描画の規則はシーケンス図で観測済みだが、すべて `SequenceDiagram` エディタでの観測。ERDiagram で同じかは検証する。

## 実装順と実機ゲート

1. **ゲートA（調査）**: コピーのプロジェクトでクラス図を開き「クラス図調査」。出力をローカル知識へ保存し、`ClassSyncOptions` の対応表を実測値で埋める（0.1.1）。
2. **ゲートB（往復）**: PlantUmlTool で同じ図を出力し、無編集で「差分を検証」して 0 件。残差は `_current.puml` との比較で読取り側を直す。
3. 0.2.0: 属性・操作の本文更新。`SetField` で名前・型・可視性を 1 件ずつ更新し、読戻し・Undo/Redo・保存再読込を照合する（`model-update-howto.md` の手順）。
4. 0.3.0: 参照関連の追加削除。`IModel.Relate / Unrelate` が通るか、JSON インポートで関連端を書く必要があるかを一時モデルで検証する。コネクタ図形の自動生成有無を観測する。
5. 0.4.0: クラスの追加削除。`AddNewModel` + `IDiagram.AddNodeShape` と Editor JSON 再反映のどちらが図形・区画を正しく作るかを検証する。
6. 0.5.0: 複数種混在・再実行・失敗注入。実機で Undo/Redo・保存・再読込・Git 差分を確認する。
7. 通常タブへの統合。実機未確認の変更を通常コマンドへ公開しない。

## 未対応の構造差分に対する方針

| 差分 | 方針 |
|---|---|
| 図に載っていないクラスへの関連 | 対象外。要照合項目として報告する |
| 所有関連（`IsEmbedded`）の線 | 読まない。出力側と同じ |
| 自己参照 | 読まない。出力側と同じ |
| 同名メンバの重複 | 兄弟列の並びで対応付ける。曖昧なら再作成候補 |
| クラスの宣言順 | 差分にしない。座標が決める |
| 所有先の変更（package 間の移動） | `move` として検出。反映は 0.4.0 以降 |

## 検査とソース構成

`ClassImportProbe/sync/` が正本。`bundle.py` が `main.cs` の生成区画へ埋め込む。生成区画は直接編集しない。

```powershell
python ClassImportProbe/sync/bundle.py
python ClassImportProbe/tests/run_tests.py --sdk-root work/sequence-api-research
```

診断レポートは実行PCの `%LOCALAPPDATA%\NextDesign.ClassSync\reports` へ保存する。モデル名やIDを含むため、公開リポジトリへ追加しない。
